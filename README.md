# Мегаполис Груп — репозиторий сайта

## Страница-прокладка `/wa` (сквозная аналитика → WhatsApp)

### Как это работает

```
Рекламная ссылка
  └─► /wa?src=tg_pablik_01&utm_source=telegram
          │
          ├─ Загружается Яндекс.Метрика → фиксирует визит, получает visit_id
          ├─ Загружается OLChat Link Modifier → вставляет visit_id в ссылку кнопки
          │
          └─► Кнопка «Написать в WhatsApp»
                  │
                  └─► WhatsApp открывается с текстом:
                      «Здравствуйте! Интересует квартира. Код: 12345678»
                              │
                              └─► OLChat распознаёт Код → пишет в B24 (UF_CRM_OLCHAT_VISIT_ID)
```

---

### Первоначальная настройка — 3 плейсхолдера

Откройте `wa/index.html` и замените все вхождения:

| Плейсхолдер | Что подставить | Пример |
|---|---|---|
| `METRICA_COUNTER_ID` | Номер счётчика Яндекс.Метрики | `98765432` |
| `WA_PHONE` | Номер WhatsApp (страна + номер, без `+` и пробелов) | `79991234567` |
| `OLCHAT_SCRIPT_URL` | URL скрипта из кабинета OLChat → Настройки → Link Modifier | `https://cdn.olchat.io/lm/xxxxxxxx.js` |

После замены в файле должны отсутствовать строки с этими словами.

---

### Настройка OLChat (кабинет)

1. **Шаблон сообщения** в настройках OLChat Link Modifier:
   ```
   Здравствуйте! Интересует квартира. Код: {visit_id}
   ```
   Должен **точно совпадать** с `messageTemplate` в `wa/index.html`.

2. **Бот-помощник** OLChat:
   - Парсить из первого сообщения `Код: <значение>`
   - Записывать значение в поле Битрикс24: `UF_CRM_OLCHAT_VISIT_ID`

---

### Настройка Битрикс24

Создать пользовательское поле в **Лиде** (или Сделке):
- Код поля: `UF_CRM_OLCHAT_VISIT_ID`
- Тип: строка

---

### Разметка рекламных ссылок

Используйте один формат для всех источников:

```
https://вашдомен/wa?src=ИСТОЧНИК&utm_source=КАНАЛ&utm_medium=ТИП&utm_campaign=КАМПАНИЯ
```

Примеры:

| Источник | Ссылка |
|---|---|
| Telegram-паблик 01 | `/wa?src=tg_pablik_01&utm_source=telegram&utm_medium=social` |
| Telegram-паблик 02 | `/wa?src=tg_pablik_02&utm_source=telegram&utm_medium=social` |
| Instagram-блогер 03 | `/wa?src=insta_blog_03&utm_source=instagram&utm_medium=influencer` |

---

### Чек-лист проверки перед запуском

- [ ] В `wa/index.html` заменены все 3 плейсхолдера
- [ ] Страница `/wa` открывается и отображает кнопку (не редирект, а страница с кнопкой)
- [ ] В Яндекс.Метрике (раздел «В реальном времени») виден визит при открытии `/wa`
- [ ] Нажатие кнопки → WhatsApp открывается с текстом, содержащим числовой `visit_id`
- [ ] После отправки сообщения в Битрикс24 создался лид/сделка
- [ ] Поле `UF_CRM_OLCHAT_VISIT_ID` заполнено
- [ ] Тест на iOS Safari и Android Chrome (минимум по одному)

---

### Хостинг

- **Apache**: `.htaccess` в корне уже настроен, маршрут `/wa` → `/wa/index.html` работает.
- **Nginx**: добавьте в конфиг сервера:
  ```nginx
  location = /wa {
      try_files /wa/index.html =404;
  }
  ```
- **GitHub Pages**: страница доступна по адресу `/wa/` (с trailing-slash).
